# IMPLEMENTATION ADDENDUM — FUNCTIONAL NODE.JS FULL-STACK PORTFOLIO

## Project Goal
Build the portfolio from zero as a clean, functional Node.js + Express + EJS application. Do not preserve an old project structure. The UI must be data-driven from `data/portfolio.json` and all major interactions must work.

## Reference Layout
Use https://rendi-fadilah.netlify.app/ only as inspiration for content hierarchy and grid structure: Hero, experience/project timeline, tech-stack chips, featured projects, and contact. Do not copy its visual design. Transform the visual language into premium dark iOS-style glassmorphism.

## Backend
Use Node.js, Express.js, EJS, CORS, Body-Parser, and dotenv.

Required routes:
- `GET /` — render `views/index.ejs` with portfolio data.
- `GET /api/portfolio` — return portfolio JSON.
- `POST /api/contact` — validate name, email, subject, and message; return JSON success/error. For the initial version, logging/storing the message locally is sufficient; do not claim email delivery without an email service.

Use `.env` with at least `PORT=3000` and `NODE_ENV=development`.
